# 总览的三个全局页面

- 概况：工具级账号数量、今日使用摘要和少量待关注事项，不展开账号的所有额度窗口。
- 账号资源：按工具分组的紧凑账号行。每行只显示一个实际窗口的最低剩余额度摘要，保留窗口/模型组名称，不对百分比求和或平均。概况及账号资源的“查看详情”使用当前页面内的只读弹窗，不改变查询账号、侧栏选择、筛选或滚动位置。授权和完整操作仍在既有工具页面/管理入口。
- 使用分布：按工具、项目或模型查看本机记录，支持搜索、展开全部、当前/上期对比和按变化排序。这里不再嵌入单工具用量页或完整会话页，操作通过“在工具中查看”跳转到原有用量或会话模块。

## 口径

今天、近 7 天和近 30 天按本地日历计算，当前与上期均截至同一当地时刻。当前和上期的日切片会截断到对应截止时刻；不是用会话终身总量充当区间数据。

跨工具项目只有工作目录完整路径相同才合并。无归属的记录按工具分开；同名模型保留工具来源，不把不同平台的同名模型擅自合并。项目贡献只有在 Tokens 和金额都对齐汇总后才参与比较；缺少上期明细显示缺失标记，不补成零。上期有用量而当前消失的模型和项目保留零当前值，以便观察减少。

比较的是已记录的 Tokens，不代表工具性能、实际付费或全部云端使用量。不将任务步数、会话数与 Tokens 混为同一指标。单工具详细计价、缓存构成、趋势、会话内容及分页仅在原有工具模块维护。

账号可用表示最近一次验证成功。缓存、授权和数据异常分别提示；不输出“所有工具健康”的笼统结论。Antigravity 额度标题保留额度组与窗口类型，避免多个相同英文窗口名称失去区分。

界面显示短版本号，不显示构建标识。没有向真实运行数据写入测试夹具。
