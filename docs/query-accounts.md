# 独立查询账号

## 账号目录与历史

账号选择器、账号管理页和总览账号摘要只读取已保存的凭据账号目录，不再把 SQLite 中出现过的账号当作可查询账号。新凭据必须经服务端身份和额度查询验证成功，才进入可选列表。旧版独立授权记录保留，首次验证前不作为可选账号。

数据库中的账号键、用量、预测观测、会话及历史关联全部保留。移除凭据不是删除历史；再次授权同一稳定身份可继续使用已有历史。移除后会记录自动发现排除项，用户主动重新导入可解除。

可用表示最近一次验证成功，而不是永久保证：有刷新令牌时访问令牌到期会尝试自动续期；无刷新令牌或远端撤销授权时需补充授权。网络超时、限流和服务错误不冒充授权撤销。

## 添加与保存

- Codex 浏览器授权：复用独立 app-server 登录流程。授权完成后加密保存 auth 数据；每次查询只在私有临时 CODEX_HOME 中展开，进程退出后保存可能已轮换的凭据并删除临时目录。不修改工具自己的目录。目录权限 0700，临时授权文件权限 0600；异常断电或进程被强制杀死仍可能留下临时文件。
- Claude 浏览器授权：PKCE + state，使用浏览器返回的授权码完成交换；只请求用于账号资料查询的范围，不请求创建 API Key、上传文件或会话管理权限。实际授权范围是否足以查询用量，需要用户登录后的服务端响应确认。
- Antigravity 浏览器授权：Google OAuth，PKCE + state，随机端口且仅监听 127.0.0.1；回调校验路径、唯一 code 和 state，超时或取消后关闭监听。请求身份及 cloud-platform 范围；不启动或注入 IDE。
- 文件 / JSON / Token 导入：限 8 MB、200 项，支持单账号、数组、accounts 容器和 QuotaLens 自身导出格式。对照 Cockpit 导出器支持 Antigravity 的 email + refresh_token 数组、完整 token 对象及 expiry_timestamp / is_gcp_tos，Codex 的 tokens 对象和 Claude 的 claude_credentials_raw / claudeAiOauth 对象。丢弃密码、2FA 等无关字段，不采用文件中的任意服务器地址。API Key、桌面 Cookie 授权或不支持的 OAuth 客户端会给出明确提示。
- 自动发现：仅对已启用工具在 QuotaLens 运行期间每分钟检查本机凭据文件变化。Claude 不再读取工具钥匙串；仅存于钥匙串的凭据需由用户重新导入或授权。

所有新凭据使用 CryptoKit AES-256-GCM 保存到本地加密存储，记录标识作为认证附加数据，防止密文串换。随机主密钥保存在独立 master.key 文件中，密钥与密文权限为 0600，目录为 0700；写入采用原子替换，进程间文件锁串行化主密钥创建与读写。密钥丢失或不匹配不自动重新生成或覆盖密文。拥有密钥和密文的同一用户进程仍可解密，此方案不是钥匙串等强度的隔离。偏好设置只存元数据。

v1.1.0 不提供钥匙串或早期明文测试格式的兼容迁移。旧授权不会自动搬运，升级后未显示的账号需要重新导入或授权；历史数据库保留。系统拒绝删除的钥匙串残留由用户在“钥匙串访问”中清理，新版不会读写它。

## 刷新边界

选择账号改变的是查询身份，不是工具的登录身份。查询请求固定使用选中账号的凭据；返回身份与期望不符时，不保存到其他账号。查询不会注入配置、重启工具或执行模型调用、重置卡消费等操作。

浏览器独立授权允许按访问令牌到期时间或明确的认证失败更新凭据；刷新结果只保存到 QuotaLens 的私有加密存储。同一查询存储串行执行刷新，避免并发轮换。保存失败时内存保留已轮换的凭据供重试。

独立授权在应用运行期间按分钟检查临近到期的访问令牌，并自动续期；续期成功后持久化新令牌、到期时间及可续期状态。服务端拒绝刷新授权时才提示重新授权。凭据文件缺失、访问令牌到期、网络失败分别反馈，不再混为授权失效。

所有具备有效 refresh_token 的账号默认自动续期，不提供全局或单账号开关，旧版关闭标记不再参与判断。仅刷新令牌的 Cockpit 导出文件会先续期再验证身份。本机捕获、文件及手动 Token 导入可能与其他客户端共享授权，更换共享令牌可能影响原客户端后续刷新；此风险保留为导入说明。id_token 到期不作为续期依据；续期不延长订阅或增加额度。

手动本机导入无文件、失败或健康独立授权无需替换时都有明确反馈。批量文件逐项验证，显示处理进度、导入或更新/未变更/失败项数及失败原因。只有服务端身份和额度验证成功的条目才入库；续期后查询暂时失败的令牌暂存在内存以供本次运行重试，不用旧刷新令牌反复轮换。

支持单账号及当前工具全部账号导出。导出前提示明文 Token 风险，用户通过系统文件对话框选择保存位置；文件默认权限 0600，不导出本地加密主密钥、密码或 2FA 字段。导出不触发网络刷新。导入来源标签不能伪装为独立浏览器授权。

移除凭据仅删除对应的本地密文，不删除历史数据库。未完成授权生成的临时目录由授权流程清理。

## 数据范围与验证限制

额度概览显示所选账号查询结果。额度预测读取该账号已有观测；Codex 独立 app-server 查询可继续采集云端累计 tokens。直接访问令牌导入的额度接口没有累计 tokens 时，不伪造容量观测或回填本机会话。

本地用量、会话与历史统计继续维持已有本机数据范围，不能凭授权取得接口未公开的完整云端历史。菜单栏和悬浮窗继续跟随工具当前身份，与主窗口的查询选择隔离。

自动测试使用合成凭据、临时加密目录、模拟 HTTP 和独立临时数据库，不使用真实账号授权。浏览器授权、真实 API 可用性和平台策略仍需用户实际授权后验证。
