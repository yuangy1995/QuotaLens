# 本地扫描诊断

Antigravity 扫描协调器保存最近一次检查的来源问题、原因及时间。顶部警告、页内“查看问题”和设置中的“Antigravity · 扫描问题”使用同一次扫描结果。重试仅重新读取 Antigravity 本地来源，不清理数据库、不切换账号、不修改工具登录。

- 读取失败来源：数据库或目录无法读取的来源数量。
- 格式不兼容来源：已读取但不能识别的活动索引或用量元数据来源数量。
- 尚未检查、未找到来源或整体扫描异常而无法列出来源时，数量显示“未检查”或“未知”，不冒充 0。
- 成功重试后使用新问题列表替换旧列表；未完整读取时保留已有统计，不将缓存误报为本次新读出的数据。

“已索引记录诊断”是另外的范围：来源文件缺失仅统计已索引且确认不存在的路径；权限或其他访问错误计入“索引来源访问异常”，不能视作文件缺失。解析失败行数来自已有导入索引，不代表 Antigravity 数据源错误数。两个范围不做简单相加。

历史加载和启动存储警告也在当前页展示问题。历史加载可重试；启动存储问题提示重新启动检查，不自动清空数据库。

`ScanDiagnosticsTests` 使用临时数据库和合成损坏来源验证分类、未知值、权限错误、重试清除和多语言覆盖，不读写真实账号凭据。
