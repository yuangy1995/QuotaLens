# 重置卡历史

历史使用独立只读接口 GET https://chatgpt.com/backend-api/wham/rate-limit-reset-credits/history，不使用现有额度接口中的可用卡片列表推断使用记录。

实测返回字段为 events、as_of、window_start、next_cursor；事件字段为 id、kind、occurred_at。已观察到 granted 和 used 类型。界面按事件发生时间显示“获得重置卡”和“使用重置卡”，可筛选仅已使用；不会假定事件 ID 等同于卡片 ID，也不虚构接口未返回的卡片标题或重置类型。

界面显示 API 给出的历史时间范围，不声称是账号全部历史。支持 next_cursor 分页及按事件 ID 去重。缓存按账号分开，账号改变时立即清空上一账号的显示；请求失败可保留同一账号上次结果并明确提示。

读取绑定当前重置卡模块的账号身份，访问令牌声明与账号键不符时不发送请求。接口只使用 GET，不消费卡片、不触发重置、不修改现有幂等兑换流程。进入模块、手动刷新以及使用卡片后可更新历史；普通状态更新至多每分钟尝试一次。

ResetCreditHistoryTests 覆盖实际响应结构、微秒时间格式、已使用筛选、分页去重、缓存隔离、GET 与账号绑定及组件渲染。对真实 API 的检查仅输出字段名、事件类型计数和范围，没有记录 Token 或响应中的账号标识。
